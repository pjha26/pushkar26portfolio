# Blue / rose dark-mode refinement

The user's supplied futuristic portrait reference is the color and lighting direction. This update refines the existing portfolio rather than replacing its routes, copy, or interactions.

## Tokens

| Role | Dark value | Treatment |
| --- | --- | --- |
| Canvas | `#030407` | Nearly black, with localized light around the portrait |
| Surface | `#090c13` | Quiet panels without a broad gray-purple wash |
| Cerulean blue | `#46bfff` | Primary actions, headline lead, links and focus accents |
| Neon rose | `#f02eaa` | Headline outcome, portrait edge light and existing signal accents |

The original ice-silver, aubergine, and marigold light tokens and light portrait are preserved. Dark browser chrome and the web manifest match the new canvas.

## Reference comparison

| Reference cue | Implementation |
| --- | --- |
| Black dominates the frame | Reduced the large background wash to small portrait-side glows |
| Blue and rose headline hierarchy | Blue lead and rose outcome; normal supporting text remains white/muted |
| Strong blue/pink portrait lighting | Original portrait relit with blue on the left and rose on the right |
| Image blends into the dark canvas | Transparent portrait asset, darker art backdrop and a quieter surrounding card |
| Bold contemporary lettering | Existing Bricolage headings retained; dark hero's serif emphasis uses the heading face |
| Existing portfolio must still work | Brush/Unbrush, sound, page movement and closing scene retained; phone text stays visible |

The person, developer copy, and portfolio structure are intentional differences from the reference. The generated portrait retains the same identity and pose; the reference's cyborg character is not copied. A complete headline preview is shown in **Unbrush** mode; the default brush discovery remains available.

## UI/UX Pro Max use

Used [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), revision `713eef5`, from a temporary local checkout. No package or global skill installation was needed.

- `cyberpunk neon portfolio --domain style -n 1` returned **Retro-Futurism**.
- `dark mode contrast --domain ux -n 2` returned **Contrast Readability** and **Color Contrast**.
- Adopted the dark canvas, blue/rose accent relationship, semantic tokens, focus/readability checks, and reduced-motion guidance.
- Kept the user's reference palette instead of accepting the database palette wholesale. Scanlines, glitch animations, and additional animation libraries are outside this refinement.

Framer was checked through the available plugin tools: provider search returned no match, and no Framer-specific tools were exposed. This update was implemented in the existing Next.js project.

## Assets and validation

- Dark portrait: `public/pushkar-neon-portrait.webp`, 1000 × 1052, transparent, approximately 164 KB. Generated by relighting the existing portrait, then encoded as WebP.
- Light portrait: original `public/pushkar-3d-portrait.png` remains intact.
- The theme-aware image subscribes to the existing HTML theme attribute, so it updates with the current theme control without mounting two visible images.
- Checked desktop fit, mobile reflow, dark-to-light portrait switching, and Brush/Unbrush. Contrast checks include the dark rose text against the canvas.
- Physical-device, Safari, and complete assistive-technology testing remain separate checks.
